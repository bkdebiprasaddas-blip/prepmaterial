✍️ How to Write in Exam — Exam Writing Guide

One global guide for the whole question bank. Match your answer length to the marks, use headings, and keep every point meaningful — depth comes from content, not repetition.

1 Mark

Write the direct definition, exact term, or the command itself. 1–3 lines. No background, no example. Get the keyword right.

2 Marks

Definition or direct point + one short explanation, or two clearly explained points. About ¼–½ page.

3 Marks

Short introduction/definition + about three meaningful points with one line of explanation each; add a tiny example if useful. ½–¾ page.

4 Marks

Definition/introduction, 4–6 developed points, an example or command/syntax where relevant, and one closing line. About ¾–1 page.

5 Marks

Introduction + definition + 5–7 explained points + example/code where relevant + a one-line conclusion. 1–1¼ pages.

6 Marks

Use subheadings: definition, detailed explanation, working/process or command options, example, and a short conclusion. 1¼–1½ pages.

7 Marks

A full university-style answer: introduction, definition, components/features, working/steps, example or code, advantages/uses where relevant, conclusion. 1½–2 pages.

  • Start with the definition, then explain — examiners award marks at clear points, so use numbered points with short explanations under each.
  • Underline or highlight key technical terms (command names, variables, modes, file names) — they are the mark carriers.
  • For command questions, write the exact command, then one line on what it does; add a sample output only if space allows.
  • For script questions, write the complete script first, then explain the important lines and show sample input/output.
  • Draw simple labeled diagrams (tree, hierarchy, flow) for directory structure, architecture, boot sequence, or loop-flow questions — a labeled diagram earns separate marks.
  • For difference questions, use a two-column comparison: every row must be a real, distinct difference.
  • Fill page coverage with different academic points (definition → working → example → uses) — never by repeating the same sentence.
  • End substantial answers with a 2–3 line conclusion that restates the concept in your own words.
  • Keep handwriting tidy, leave margin, and leave time for the final 1-mark and MCQ section — they are quick mark-winners.
