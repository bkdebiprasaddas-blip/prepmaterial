✏️ How to Write in Exam — Global Guide

Use this guide for every answer in this question bank. Match the depth of your answer to the marks of the question — nothing more, nothing less.

1–2 Marks

Write the direct definition, fact or required points only. No introduction, no conclusion. 2–5 lines are enough.

5 Marks

Start with a definition, then give 5–7 explained points or a short structured description. Add a small diagram/example where relevant. Finish with one-line conclusion.

6–8 Marks

Use clear headings: introduction → definition → explanation → diagram/working → advantages/applications → conclusion. Explain each important point, don’t just list it.

10–14 Marks

Write a complete university answer: all major sections, labelled diagrams, comparison tables where relevant, applications, limitations and a firm conclusion.

  • Underline keywords and technical terms (OSI, TCP, topology…) so the examiner spots them instantly.
  • Number your points and use subheadings — answers become easy to mark and hard to lose marks on.
  • Draw labelled diagrams with a pencil and scale whenever the topic is visual (topologies, OSI layers, headers).
  • Match length to marks: 2 marks ≈ ¼ page · 5 marks ≈ 1 page · 6 marks ≈ 1½ pages · 8 marks ≈ 2–2½ pages.
  • Write code/protocol formats neatly with proper indentation and explain important lines.
  • No filler: never repeat the same idea to fill pages — add a new relevant point instead.
