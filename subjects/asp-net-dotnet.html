✍️ How to Write in Exam — Global Writing Guide

MarksWhat to write
1 markWrite the exact definition, fact or MCQ option. No extra explanation needed.
2 marksDefinition + 1–2 key points or a tiny example.
3 marksShort definition + about 3 clear points + example if useful.
4 marksIntroduction/definition, 4–6 explained points, example/syntax/diagram if relevant, short conclusion. (≈ ¾–1 page)
8–10 marksFull university answer: introduction, definition, detailed explanation, components, working, example/code/diagram, advantages, conclusion. (≈ 2–3 pages)
12–14 marksComplete multi-section answer with subheadings, diagrams/code, advantages & limitations, applications and conclusion. (≈ 3–5 pages)
  • Underline keywords — DataSet, CLR, DataAdapter, Session — examiners scan for them.
  • Use headings and numbered points; never write one solid paragraph.
  • Draw labelled diagrams (page life cycle, ADO.NET architecture) — they earn easy marks.
  • Write code with proper indentation and add 2–3 lines of explanation after it.
  • In comparison questions, always use a table with a "Basis" column.
  • Match depth to marks — a 1-mark answer should be 1–3 lines, never a page.
  • Finish long answers with a 2-line conclusion.
  • Avoid filler; every sentence should carry a mark-bearing fact.
