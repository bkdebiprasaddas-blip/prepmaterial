## Gotchas hit

- **A literal backtick inside a JS template literal breaks the build script.**
  Used `String.fromCharCode(96)` in the browser probe.
- **`element.getComputedStyle` does not exist.** An early `vis()` helper used
  it and silently reported 0 visible cards, which looked like a filter bug.
- **HTML allows a raw `<` inside a quoted attribute value.** Several retained
  cards hold a literal `<strong>` in `data-text`, so any `[^>]*` tag regex
  truncates them. Scan opening tags with quote awareness.
- **PowerShell mangles inline `node -e`** with quotes/backticks. Write a `.js`
  file instead of fighting the shell.
