## Root cause — what was actually broken

Commit `0fd1c8c` ("Rebuild UNIX question bank by syllabus units") replaced the
question data with the MD's structure but **deleted four things** the page needs
to function:

1. The `MA` object (15 master long answers).
2. The `MB` object (31 master long answers).
3. Every MCQ `ans` (correct option) and `why` (explanation) field.
4. **The page's helper functions** — `const $`, `const $$`, `esc()`,
   `stripHTML()`, `hi()`, `LS_BM`, `LS_TH`.

Item 4 is the real breakage. Headless Chrome reported:
`Uncaught ReferenceError: $ is not defined` at line 4140. Because
`render()` is called from the init block and every render helper uses `$()`,
the script died before painting — `#list`, `#stats` and `#sidebar` were all
**empty**. The page looked completely blank of questions. So the committed
version was not merely "missing answers", it was non-functional.

## Decisions

- **Keep the MD structure** (user's explicit requirement): 12 unit sections,
  A/B/C × Units 1–4, IDs `sec-a-*` / `sec-b-*` / `sec-c-*`. Not reverted.
- **Restore answers from the pre-rebuild version** (`0fd1c8c^`) rather than
  authoring new ones — preserves the user's own vetted answer wording.
- **Map old → new by content, not by position**: MCQs matched on their option
  list (stable), short questions on normalised question text, long questions
  on an explicit per-ID topic table (deterministic, reviewable).
- **New `SB` object for 34 short questions** that had no counterpart in the old
  file. These are the "write a command" and definition questions the old
  version never answered. Authored fresh, matching the established answer
  style (definition box → explanation → examples → quick revision).

## Notable bugs hit and fixed during this work

- **MB section boundary.** `const MB = {};` → `const SECTIONS = QB;`
  over-captured 161 649 chars including 61 `mcq-*` and 72 `m1-*` entries,
  because the old file interleaves the objects. Fixed by locating the **last
  `MB.<name> = \`` assignment** and cutting at its closing `` `; `` → clean
  83 308 chars, 0 leakage.
- **Octal escape in template literal.** Authored answer contained
  `sed -i '2c\102 …'`; `\102` is an illegal octal escape inside a template
  literal and broke the whole script block. Fixed by doubling all 47
  backslashes in the authored answers.
- **Unquoted HTML answers.** Text-matched short answers were emitted as bare
  `a:<p>…</p>` instead of `a:"<p>…</p>"`, producing 473 `SyntaxError`s. Fixed
  with an explicit `aKind` discriminator (`'html'` → quote + escape,
  `'ref'` → emit bare `MA.x`).
- **Duplicate question arrays.** An early pass left the old `mcq-*` array
  alongside the new `sec-a-*` array (213 questions instead of 214). Fixed by
  replacing the whole `const QB` … `const SECTIONS` span, not patching in place.
- **PowerShell eats inline regex.** `node -e "…"` with `[^\]]` etc. was
  repeatedly mangled by PowerShell parsing. All scripts were moved to files and
  invoked as `node <file>`.
