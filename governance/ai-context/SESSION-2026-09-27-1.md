## Gotchas hit (worth remembering)

- **Do not write before validating.** An early version of the script wrote
  first and asserted after, so a failed assertion left a half-transformed
  file. Moved all validation in-memory, pre-write.
- **PowerShell here-strings keep a trailing `\n`.** `@"..."@` ending on a
  newline added a stray blank line, which silently broke a 4-line anchor
  match. Needed `.TrimEnd("`r","`n")`.
- **Anchors must match real whitespace.** Assumed `</div>\n      </div>\n
  </section>\n\n`; actual was `</div>\n      </div>\n    </section>\n\n`.
  Dump the region before writing an anchor, don't assume.
- **`paper-2025-new-mcq` already existed** in the source — I had "fixed" a
  phantom missing heading and created a duplicate id. Check the source before
  adding a group.
- **Cascading renumber.** Replacing tile `4`→`3` then `5`→`4` renumbered the
  tile `4` had just become. Fixed with a single pass + `@@n@@` placeholders,
  and finally by matching on heading *text* rather than number.
