# Second session, later the same day

## What I set out to do

You pointed out that the AWD question-bank **Markdown file holds 312
questions**, but the web page only had 261. So the page was missing 51
questions' worth of content, and the way it was organised (by marks only) didn't
match the syllabus. The job was to rebuild the page around the syllabus's four
units and their topics, write answers for the missing questions, and fix a few
questions that had no correct answer.

## What I did

**Reorganised by syllabus instead of by marks.** The page is now four unit
sections, each split into its topics (22 topics in total), plus the existing
Reference section. Every question now carries three extra labels: which unit it
belongs to, which topic, and which past paper it came from. That last one used
to live in section headings, which no longer exist now that the paper headings
are gone — so I moved it onto each question itself, and nothing was lost.

**Added 57 new questions with full answers.** These were real gaps in the page:

- 41 one-mark MCQs, each with the correct option highlighted and a short
  explanation of *why* it's right.
- 3 one-mark short answers and 13 five-mark answers, written in the same style
  as the existing ones — a headline definition, examples with code, comparison
  tables, exam-tip lines and a quick-revision list at the end.

Every topic now has a sensible spread: Unit 1 has 99 questions, Unit 2 has 104,
Unit 3 has 36, Unit 4 has 58, and 15 reference questions.

**Removed 6 questions that genuinely had no right answer** — for example one
asked which HTML element to use for a dropdown and offered `<Select>` with a
capital S, which doesn't exist. Rather than keep a broken question, I removed it.

**Fixed 6 more** by writing them correctly: one said `db.aggregate()` (MongoDB
needs the collection name in the middle), one used `componentShouldUpdate`
instead of `shouldComponentUpdate`, one offered a non-existent `<Select>`, and
three had wording that made more than one option defensible. You also said not
to invent extra questions just to fill topic 4.6, so I left that topic as it is
— the questions that would have filled it are already covered elsewhere.

**Fixed six real page bugs** found while checking:

1. A piece of sample HTML inside an answer contained a `</script>` tag. That
   silently cut the page's JavaScript in half — the page's buttons and filters
   would have stopped working. Now escaped properly.
2. The 57 new questions showed "Q?" instead of a number. Now numbered 1–312 in
   reading order.
3. The 255 existing questions were missing their new unit/topic/paper labels, so
   the filters would have ignored them. Now added.
4. One of my own answers had a missing backtick, which left a stray character on
   screen. Fixed.
5. Five diagrams had literal `<pre>` tags showing as text. Fixed.
6. A dollar sign inside MongoDB sample text was being mangled by a JavaScript
   quirk. Fixed.
